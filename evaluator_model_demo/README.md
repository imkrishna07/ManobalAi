# Manobal-AI model backend demo

This folder is an evaluator-facing snapshot of the model used by the Manobal-AI backend.

## What it demonstrates

- A calibrated LightGBM model (`0.3.0-synthetic-backend-compatible`).
- Backend feature contract `1.1.0`: 44 ordered features generated from raw weekly records.
- Bundled preprocessing and baseline artifacts.
- A passing smoke test that loads the bundled model and performs inference through the backend's raw-record pipeline.
- A held-out synthetic test-set report in `model_metadata.json` and `MODEL_CARD.md`.

## Run the smoke test

From the ManobalAi project root, with Docker available:

```bash
docker compose build backend
docker compose run --rm --no-deps backend python -m pytest -q -o addopts= tests/test_evaluator_model_smoke.py
```

The checked result from this project is recorded in `test-results.txt`. The test covers artifact loading, 44-feature schema/order, prediction output, and normalized class probabilities.

## Evaluation results

The model was evaluated on 7,800 held-out synthetic person-weeks, with people separated between train, validation, and test splits. Full metrics are in `artifacts/model_metadata.json`:

| Metric | Result |
| --- | ---: |
| Accuracy | 0.650 |
| Balanced accuracy | 0.581 |
| Macro F1 | 0.577 |
| Log loss | 0.758 |
| Low / Moderate / High recall | 0.837 / 0.331 / 0.574 |

## Important limitation

The records and labels are generated by a simulation, not collected real-world outcomes. These metrics show that the code runs and how well the model reproduces its simulated labels; they do not establish real-world accuracy, clinical validity, or production readiness. The output is for a human-reviewed hackathon demo only.

See `MODEL_CARD.md` for intended use and limitations. The executable smoke test is included under `backend/tests/`.
